# Course Intro Demo App

This is a small Expo app intended for the lesson-01 instructor demo.

## Demo Goals
- Show that a mobile app can have multiple screens within one project.
- Surface familiar UI building blocks: headings, cards, lists, buttons, badges, and text input.
- Give students a concrete example to analyze before they install tooling in lesson 02.

## Course Standard
This demo app should remain aligned with the course baseline:
- Expo SDK 56
- React Native 0.85
- React 19.2.x

## Run
1. Install dependencies:
   - `npm install`
2. Start Expo:
   - `npm run start`
3. Open on:
   - Android emulator
     - `npm run android`
   - iOS simulator
   - Expo Go on a physical device

## Suggested Demo Route
1. Home screen: show the course focus cards.
2. Explore screen: compare native, hybrid, and cross-platform tradeoffs.
3. Planner screen: toggle interests and add a note to show state updates.
4. Return to the home screen and ask students which components and navigation patterns they can name.

## Teaching Note
Students are not expected to understand every line of code yet. The app exists to make later lessons feel familiar.
